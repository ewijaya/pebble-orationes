# Chapel promotional artwork

Chapel is for promotional artwork only. The watch keeps its existing cyan accent,
black/white contrast, fonts, icons, and layout. Screens shown in this campaign are
unaltered native Emery captures of v0.7.0 in Dark / Ocean / Large.

Palette: ivory `#F6F0E5`, burgundy `#70283D`, gold `#B69A60`, ink `#252524`.
Typography: Georgia headlines and Helvetica Neue supporting text.
The O-and-cross geometry develops the existing vector mark. Watch frames are
illustrations, not photographs. Category symbols and the bookmark live outside
the watch display and do not imply new in-app controls.

## Regenerate

Run `python3 scripts/render_promo.py` from the repository root. Requires
`rsvg-convert` and the fonts named above. No Pebble rebuild is needed.
Native screenshots must be recaptured from the app; never recolor or retype them.

## How the ten suggestions were applied

1. Chapel palette: promotional surfaces only.
2. Benefit headline: “Make time for prayer.”
3. Campaign composition: ivory, burgundy panel, arch, restrained gold, real screen.
4. App accent: preserved; featured through the existing cyan-on-dark appearance.
5. Branding: compact O-and-cross and wordmark on artwork, no watch header added.
6. Gallery: read, Continue, browse, personalize.
7. Typography: promotional serif headlines, clear supporting text and spacing.
8. Continue: dedicated card with a bookmark symbol outside the screenshot.
9. Categories: an external illustrated category guide; native menu unchanged.
10. Icon: consistent vector mark and clean exports; native launcher icon unchanged.

## Platform constraints

RePebble’s Edit Listing form exposes banner, small/large icons, screenshots, and
text fields. It exposes no custom OG upload. Its `/og/<app-id>.png` share-card
layout is generated by the platform. A listing-banner upload is not a replacement
for that OG image. Use the custom card directly when sharing.

Store release v0.6.0 remains unchanged. The store campaign uses prayer screens
compatible with that version; Continue and All Prayers artwork is for v0.7.0 on
GitHub. No new watch release is part of this visual update.
