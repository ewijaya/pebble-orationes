# Store assets

The current Chapel banner, icons, and social preview are generated by
`python3 scripts/render_promo.py`. See [campaign guide](../promo/README.md) for
palette, editable sources, screenshot provenance, and platform limitations.

| File | Size | Purpose |
| --- | --- | --- |
| `banner-720x320.png` | 720x320 | RePebble listing banner |
| `icon-144.png` | 144x144 | Large listing icon |
| `icon-80.png` | 80x80 | Small listing icon |
| `social-preview-1280x640.png` | 1280x640 | GitHub social-preview upload asset |
| `source/social-preview-1280x640.svg` | Vector | Editable social-preview export |
| `source/icon-master-1254.png` | 1254x1254 | Original icon retained for reference |

The in-watch launcher icon at `resources/images/orationes-menu-icon.png` is
unchanged. The custom social preview cannot be uploaded as the RePebble OG card;
that platform controls its share-card template.
