# Store assets

The approved realistic main-menu artwork is the definitive social preview and
store-banner choice. The README uses its full-resolution master. Both PNGs are
retained as supplied.

| File | Size | Purpose |
| --- | --- | --- |

| `orationes-banner-realistic-main-menu-720x320.png` | 720×320 | Definitive social preview and listing banner |
| `icon-144.png` | 144×144 | Large listing icon |
| `icon-80.png` | 80×80 | Small listing icon |
The previous 1280×640 social preview, store SVG sources, and their export script
have been archived. Use the approved PNG directly for sharing.

The listing icons retain their existing Chapel artwork. The native watch mark
is maintained separately in `resources/images/`. For native
store screenshots, see the [raw screenshot guide](../raw/README.md).

The older campaign, typographic banner, design proposals, and physical photos
were archived outside the project during cleanup. See the
[cleanup record](../../image-audit.md) and retained
[campaign publication history](../promo/README.md).

Local file cleanup does not update the live listing. RePebble controls its OG-card
template; its listing banner and a custom social-preview image serve separate fields.
