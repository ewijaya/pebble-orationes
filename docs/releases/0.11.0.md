# Orationes v0.11.0

- Remember Place On now resumes saved prayer positions from any menu, including
  shortcuts, All Prayers, collections, and the Rosary's Litany of Loreto.
  Without a saved position, a prayer starts at the beginning. Remember Place Off
  always starts prayers at the beginning and clears saved places.
- Continue remains a quick link to the last saved prayer. Recent Prayers keeps
  up to eight independent places, and Start again explicitly restarts a prayer.
- New installations use Dark appearance, Ocean title accent, and Lime navigation
  highlight in both watch and Clay Settings. Existing saved preferences survive
  upgrades. Empty space below a short main menu now follows the chosen appearance.
- One Restore Defaults action replaces the shortcut-only reset. It resets all
  preferences: original shortcuts, Dark/Ocean/Lime, Large text, Remember Place On,
  Continue First Off, noon reminder Off, and 10-second reminder duration. Saved
  prayer positions are preserved. In Clay, tap Save Settings to apply the reset.
- The bottom of both watch Settings and Clay Settings displays the bundled app
  version, derived automatically from the build version.
- Release checks include automatic-resume and all-settings-reset regressions.

Prayer wording and store artwork are unchanged. Developer installation may create
a local My Apps entry without store artwork; that does not indicate a missing PBW.
