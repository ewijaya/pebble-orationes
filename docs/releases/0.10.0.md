# Orationes v0.10.0

This update makes prayers easier to open, navigate, and return to.

- Open a prayer directly with Select in All Prayers. Hold Select and release
  for Open/Pin options; a small header hint explains the controls.
- Read clearer response blocks and stanza spacing. Prayer wording is unchanged,
  and the Litany of Humility attribution remains in small print.
- Press Select while reading for Start again or Jump to section. Preces and
  both litanies have section jumps; Come, Holy Spirit has stanza jumps, and
  Aspirations has ten groups covering all 92 entries.
- Keep separate saved places for up to eight recently read prayers. A ninth
  distinct prayer replaces the oldest saved entry. Ordinary library and shortcut
  openings still start at the top.
- Continue opens the most recently saved prayer directly. The optional,
  watch-local Continue First setting places it above shortcuts; default Off.
- Release preparation now freezes one tested PBW with a source commit and
  SHA-256, requires physical approval before publishing, and verifies selected
  public destinations before synchronizing release-status documentation.

Existing shortcuts, prayer IDs, body text sizes, appearance settings, reminders,
and the phone settings protocol are preserved. Remember Place remains optional;
turning it off clears the saved history. Existing bookmarks are read on upgrade;
the older single-block Humility position is migrated approximately.

Aspirations moves to a generated resource without changing its text or styling,
leaving more room in the executable image. The app remains Emery-only and prayer
content remains available offline.
