# Orationes v0.10.1

- Continue First is now available in Clay phone Settings and synchronizes with
  the watch. Your existing preference is preserved on upgrade.
- Clay displays the bundled app version automatically.
- Continue First saves atomically with the other settings. Failed saves do not
  partially apply a phone settings batch; older payloads preserve the preference.
- Added migration, interrupted-save, phone synchronization, and emulator coverage.

Prayer content, watch reading behavior, and store artwork are unchanged.
Developer-installed builds can lack My Apps artwork because the mobile app stores
them without the store's image metadata. Use the published store build for
store-linked artwork; a developer install is not a store-metadata refresh.
