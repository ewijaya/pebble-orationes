# Orationes v0.12.1

- Make Compact Menus visibly denser: short rows use 36 pixels instead of 48,
  fitting five complete default home shortcuts below the header. Full-size fonts
  remain unchanged; wrapped names expand with less padding. Short Settings labels
  and values share a line when they fit. Spacious 54-pixel rows remain the default.
- Add Compact Menus to Clay and synchronize it in both directions with the watch.
  Existing choices survive upgrades. Watch reset and Clay Restore Defaults + Save
  Settings both turn it off; older phone payloads that omit it preserve the value.
- Request fresh watch settings when opening Clay. After two seconds without a
  reply, clearly label cached values. Late replies update the cache without
  reopening the page; pending saves retain durable confirmation and retry behavior.
- Replace Menu Help with general Help: eight selectable topics for navigation,
  reading, resuming prayers, pinning shortcuts, menu layout, phone settings,
  Holy Rosary, and the noon reminder. Instructions scroll with Up/Down; Select or
  Back returns to topics. Help does not change saved prayer positions.
- Clarify the first-use pinning hint: in All Prayers lists, hold Select and then
  release for options. Help → Pin Shortcuts explains the category, prayer, and
  main-menu slot steps.
- Expand release checks for Help scrolling, phone/watch Compact Menus changes,
  Clay refresh and cached fallback, persistence, reset, and compact text rendering.

Prayer wording, Rosary weekday mappings, default shortcuts, spacious menu layout,
and store artwork are unchanged. Install this PBW and reopen MyApps Settings to
access the new Clay toggle and refresh behavior.
