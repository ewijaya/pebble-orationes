# Orationes v0.12.2

- Put Start again first and select it initially in Reading Options throughout
  the app, including the Litany of Loreto. Jump to section follows where available.
- To return to the beginning of a prayer, press Select, wait for Reading Options
  to open, then press Select again. No Up/Down navigation is needed.
- Keep the existing controls: hold Up/Down to scroll quickly; double-click Select
  while reading to exit to the watchface.

Prayer wording, saved-settings formats, and store artwork are unchanged.
